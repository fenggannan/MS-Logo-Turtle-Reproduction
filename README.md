## 运行方法

1. 安装 Python 3（勾选 Add to PATH）。
2. 双击 `weiruan.pyw`。
3. 程序会自动画出居中的四色 Logo。

> Windows 上需要安装 Segoe UI Semibold 字体（系统自带），否则文字会回退到默认字体。

## 技术参数

| 参数 | 取值 |
|---|---|
| 方块边长 | `fd(100)` |
| 方块坐标步距 | 110（缝隙 10px） |
| 图标到文字间距 | `fd(151)` |
| 字号 | Segoe UI Semibold 126 |
| 背景色 | `#242424` |
| 四色 | `#F25022` / `#7FBA00` / `#00A4EF` / `#FFB900` |

与官方 SVG 对比，核心几何比例偏差在 **1% 以内**（间距 -0.5%、总宽 -0.8%、字宽 -1.1%、单格 +0.8%）。

## 制作过程

- v1 `fd(140)`：图标到文字偏紧（-17.9%）
- v2 `fd(160)`：间距略松（+13.7%）
- v3 `fd(151)`：正中靶心（-0.5%）

最终版通过三版数据驱动迭代完成。
